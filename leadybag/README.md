# دليل المرحلة 1️⃣ - إعداد مشروع leadybag

هذا الدليل موجّه لك كمبتدئ تماماً. اتبع الخطوات بالترتيب ولا تتخطَ أي خطوة.

---

## 📁 شرح كل ملف ومجلد (قبل ما نبدأ)

```
leadybag/
├── package.json          ← قائمة كل المكتبات (الأدوات) التي يحتاجها المشروع
├── tsconfig.json          ← إعدادات لغة TypeScript
├── next.config.js         ← إعدادات إطار العمل Next.js
├── tailwind.config.ts     ← إعدادات الألوان والتصميم (Tailwind CSS)
├── postcss.config.js      ← ملف مساعد لتشغيل Tailwind
├── .env.local.example     ← مثال لمتغيرات البيئة (كلمات سر وروابط سرية)
│
└── src/                   ← كل كود المشروع الفعلي هنا
    ├── app/                        ← الصفحات (كل مجلد = رابط/صفحة في الموقع)
    │   ├── layout.tsx              ← "الإطار" العام لكل الصفحات (يتكرر في كل صفحة)
    │   ├── page.tsx                ← الصفحة الرئيسية (الرابط: /)
    │   ├── globals.css             ← التنسيقات العامة
    │   └── api/
    │       └── health/route.ts     ← رابط اختباري: /api/health
    │
    ├── models/                     ← "نماذج" قاعدة البيانات (شكل كل جدول)
    │   ├── User.ts                 ← المستخدمين (عملاء + أدمن)
    │   ├── Category.ts             ← أقسام المتجر
    │   ├── Product.ts              ← المنتجات
    │   ├── Order.ts                ← الطلبات
    │   ├── Cart.ts                 ← سلة التسوق
    │   ├── Coupon.ts               ← الكوبونات
    │   └── Analytics.ts            ← الإحصائيات اليومية
    │
    └── lib/
        └── db.ts                   ← ملف الاتصال بقاعدة بيانات MongoDB
```

**ملاحظة مهمة**: قاعدة البيانات **فارغة تماماً** الآن. لا يوجد أي منتج أو قسم مُضاف. كل شيء سيُضاف لاحقاً يدوياً من لوحة تحكم الأدمن (في المرحلة 5).

---

## 🧰 الخطوة 1: تثبيت البرامج الأساسية على جهازك

قبل أي شيء، ثبّت هذه البرامج على جهازك (إن لم تكن مثبتة):

1. **Node.js** (نسخة 20 أو أحدث) — حمّله من: https://nodejs.org
   - للتأكد من التثبيت، افتح Terminal (أو CMD) واكتب:
     ```
     node -v
     ```
     يجب أن يظهر لك رقم إصدار مثل `v20.x.x`

2. **MongoDB** (قاعدة البيانات) — لديك خياران:
   - **الأسهل للمبتدئين**: أنشئ حساب مجاني على [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) (سحابي، لا يحتاج تثبيت على جهازك)
   - أو ثبّت MongoDB محلياً من: https://www.mongodb.com/try/download/community

---

## 📦 الخطوة 2: تحميل ملفات المشروع وتثبيت المكتبات

1. فك ضغط ملف المشروع الذي أرسلته لك في مجلد على جهازك.
2. افتح Terminal (أو CMD) داخل مجلد المشروع `leadybag`.
3. نفّذ هذا الأمر لتثبيت كل المكتبات المطلوبة (سيأخذ دقيقة أو دقيقتين):
   ```
   npm install
   ```
4. بعد الانتهاء، سيظهر مجلد جديد اسمه `node_modules` — هذا طبيعي، فيه كل المكتبات.

---

## 🔑 الخطوة 3: إعداد متغيرات البيئة

1. انسخ ملف `.env.local.example` وأعد تسميته إلى `.env.local`
2. افتح `.env.local` وعدّل السطر الخاص بـ `MONGODB_URI`:
   - إذا تستخدم MongoDB Atlas: الصق الرابط الذي أعطتك إياه المنصة
   - إذا تستخدم MongoDB محلي: اتركه كما هو `mongodb://127.0.0.1:27017/leadybag`
3. باقي المتغيرات (Redis، Cloudinary، البريد) اتركها فارغة الآن، سنعبّئها في مراحل لاحقة.

---

## ▶️ الخطوة 4: تشغيل المشروع

في نفس الـ Terminal، نفّذ:
```
npm run dev
```

سترى رسالة تقول أن الموقع يعمل على `http://localhost:3000`

---

## ✅ اختبار المرحلة 1 (لا تنتقل للمرحلة التالية قبل نجاح هذا الاختبار)

### الاختبار 1: هل تظهر الصفحة؟
افتح المتصفح واذهب إلى:
```
http://localhost:3000
```
**يجب أن ترى**: عنوان "🎉 مشروع leadybag يعمل بنجاح" بلون وردي، والصفحة تكون من اليمين لليسار (RTL) لأنها عربية.

### الاختبار 2: هل قاعدة البيانات متصلة؟
افتح المتصفح واذهب إلى:
```
http://localhost:3000/api/health
```
**يجب أن ترى** رداً بصيغة JSON يشبه هذا:
```json
{
  "status": "success",
  "message": "✅ الاتصال بقاعدة البيانات ناجح والنماذج جاهزة",
  "modelsLoaded": ["User", "Category", "Product", "Order", "Cart", "Coupon", "Analytics"]
}
```

### إذا ظهر خطأ بدلاً من ذلك:
- تأكد أن MongoDB يعمل فعلاً (إذا محلي: تأكد أن خدمة MongoDB مشغّلة على جهازك)
- تأكد أن `MONGODB_URI` في ملف `.env.local` صحيح ولا يحتوي أخطاء إملائية
- انسخ رسالة الخطأ بالضبط وأرسلها لي لأساعدك في حلها
